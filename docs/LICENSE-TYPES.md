# 授权类型增强：浮动席位 / 试用卡 / 固定到期日

> B1 批次三项能力。与既有"时长卡 / 次数卡 / 功能位"完全兼容，可按需组合。

## 一、浮动席位（并发授权）

**场景**：不按"绑定几台设备"卖，而按"同时在线几台"卖（大客户常见形态）。

**用法**：生成时设置「并发席位」> 0（管理端 / API `max_concurrent` / AI 助手参数）。

**语义**：

| 行为 | 说明 |
|---|---|
| 席位计数 | 以"活跃租约"计：设备在租约窗口（默认 90 秒，`security.seat_lease_seconds`）内有心跳/校验/首次激活即视为占座 |
| 激活 | 设备数不受 `max_devices` 限制（浮动模式忽略绑定上限）；席位满时返回 `seats_full`（**不触发换机风控**，属正常竞争） |
| 心跳 | 续约占位；本机租约已过期且席位被占满时返回 `seats_full`（客户端稍后重试即可） |
| 离线释放 | 客户端停止心跳超过租约窗口 → 席位自动释放 |
| 响应字段 | 激活/心跳返回 `seats: {limit, in_use, left, lease_seconds}`（仅浮动卡；非浮动卡响应不变） |

**客户端建议**：收到 `seats_full` 后隔一个心跳周期重试；收到即表示"暂时排队"，不是错误。

## 二、试用卡（防重复领取）

**场景**：获客入口——让每台设备免费试用一次，不能刷。

**用法**：卡密模式选「试用卡」（`card_type: "trial"`）。必须设置有效期（或固定到期日）。

**语义**：

| 行为 | 说明 |
|---|---|
| 防重领 | 同一机器码在**同一批次**内只能领取一张；同机尝试领取同批其他试用卡 → `trial_used` |
| 多批次 | 管理员可用不同批次控制"能领几次"（例如季度活动各一批） |
| 重激活 | 已领取设备的重复激活保持幂等（`already`），不受防重领限制 |
| 续期 | **不支持**（返回"试用卡不支持续期"）；恢复/吊销等管理操作不受限 |
| 兼容 | 试用卡可携带功能位、可设设备数 / 浮动席位（组合使用） |

## 三、固定到期日

**场景**：企业采购、学期授权——"统一到 2027-06-30 失效"，而非"激活后 N 天"。

**用法**：勾选「固定到期日」并填 `YYYY-MM-DD HH:MM:SS`（API：`expiry_mode:"fixed"` + `fixed_expires_at`）。

**语义**：

- 无论何时激活，到期时间恒为设定值（激活不重算）；
- 支持固定 + 浮动席位 / 功能位组合；
- 次数卡不支持固定到期日（返回 400）；
- 固定时间必须晚于当前时间（格式或过去时间返回 400）；
- 续期顺延固定日（到期时间 = 原固定日 + 续期时长）。

## 四、快速验收（已实测）

- 浮动席位：2 席卡第 3 台拒绝 → 离线释放后进入；心跳争抢场景全过
- 试用卡：同机二领拒绝 / 异机可领 / 重激活幂等 / 续期拦截
- 固定到期日：激活不改期 / 过去时间与坏格式拦截 / 次数卡拦截
- 全量回归：**421 passed**；端到端 62/62
